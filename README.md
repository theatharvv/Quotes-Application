# 📝 Quote Explorer App – Jetpack Compose

This project is a **user-friendly Quote App** built entirely using **Jetpack Compose**. It allows users to explore a **curated collection of inspiring quotes** along with their authors, all through a clean and minimalist interface.

It features smooth scrolling, responsive layouts, and local JSON-based data loading — ideal for reflecting on powerful words with a seamless user experience.

---

## 🌟 Features

- ⚡ 100% Jetpack Compose – No XML used
- 📜 Loads quotes from a local **JSON file**
- 🧘 Minimalist and calming UI design
- 🔁 Smooth scrolling through a list of quotes
- 👆 Tap any quote to view full-screen detail
- 🌗 Light/Dark theme support ready for extension
- 🧩 Modular composables for reusable UI components

---

## 🛠 What I Built

- Parsed a **local JSON file** with a list of quotes and authors using Gson
- Created a **scrollable list UI** with `LazyColumn` to show all quotes cleanly
- Built a **detailed quote view screen** with quote text and author info
- Used **Composable functions** to separate UI concerns (Card, DetailView, etc.)
- Structured project in **modular packages**: `data`, `model`, `ui`, and `screens`
- Focused on **UI polish**, **code readability**, and **component reusability**
